
Create: Power Grid — Modified

This repository contains a modified version of Create: Power Grid, originally created by patryk3211.

The original project provides a physics-based electricity simulation for the Create mod.

Original Project

Original author: patryk3211

Original repository:

https://github.com/patryk3211/PowerGrid

Modifications

This repository contains modifications and additions to the original Power Grid source code, including work on:

- Electricity simulation and network handling
- "WorldNetworks" and world/network state persistence
- Solar panels and photovoltaic generation
- MPPT control
- Battery and LiFePO4 battery simulation
- Power conversion and transformer systems
- HV switching and electrical components
- Power conditioner / inverter systems
- Other experimental electrical components and systems

Some of these modifications are experimental and may change during development.

Minecraft Version

The current development version is based on:

- Minecraft 1.20.1
- NeoForge / Forge-based Power Grid development

A separate branch is planned for the Minecraft 1.21.1 NeoForge port.

Development

This repository is primarily used for development and testing of modifications to Create: Power Grid.

The source code may contain experimental features, unfinished systems, and debugging changes.
